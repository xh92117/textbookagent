# 章节审查检查清单

## 知识维度
### 1. 知识准确性
- [ ] 概念定义是否准确
- [ ] 事实陈述是否正确
- [ ] 数据引用是否可靠

### 2. 逻辑连贯性
- [ ] 段落之间逻辑是否连贯
- [ ] 论证过程是否完整
- [ ] 结论是否由前提自然推导

### 3. 术语一致性
- [ ] 术语使用是否与大纲一致
- [ ] 同一概念是否使用统一术语
- [ ] 术语首次出现是否有定义

### 4. 难度梯度
- [ ] 章节内部难度是否递进
- [ ] 是否有突然的难度跳跃
- [ ] 是否提供了足够的过渡和铺垫

### 5. 认知层次匹配
- [ ] 内容深度是否与目标认知层次匹配
- [ ] 习题难度是否与内容层次匹配

## 内容维度
### 6. 概念定义规范
- [ ] 核心概念是否有明确定义
- [ ] 定义是否遵循"属+种差"格式
- [ ] 是否提供了正例和反例

### 7. 公式/定理正确
- [ ] 公式推导是否正确
- [ ] 定理表述是否严谨
- [ ] 边界条件是否说明

### 8. 代码示例正确
- [ ] 代码是否能正确运行
- [ ] 代码风格是否规范
- [ ] 是否有充分的注释

### 9. 图表合理性
- [ ] 图表是否必要且有价值
- [ ] 图表标注是否清晰
- [ ] 图表与正文是否一致

### 10. 习题质量
- [ ] 习题是否覆盖各认知层次
- [ ] 题目表述是否清晰无歧义
- [ ] 答案是否正确

## 结构维度
### 11. 章节结构完整
- [ ] 是否包含引言/导语
- [ ] 是否包含本章小结
- [ ] 是否包含习题

### 12. 段落划分合理
- [ ] 段落主题是否单一
- [ ] 段落长度是否适中
- [ ] 段落之间是否有过渡

### 13. 标题层级清晰
- [ ] 标题层级是否正确
- [ ] 标题是否准确概括内容
- [ ] 标题编号是否连续

## 表达维度
### 14. 语言规范性
- [ ] 是否使用学术/专业语言
- [ ] 是否避免口语化表达
- [ ] 是否避免AI痕迹语言

### 15. 表述清晰性
- [ ] 是否避免了模糊表述
- [ ] 是否避免了冗余表述
- [ ] 长句是否拆分合理

### 16. 去AI味
- [ ] 是否避免了"值得注意的是"等AI常用语
- [ ] 是否避免了过度使用"然而""此外"
- [ ] 是否避免了空洞的总结段落

## 教学维度
### 17. 教学目标明确
- [ ] 章节教学目标是否明确
- [ ] 教学目标是否可衡量
- [ ] 教学目标是否与大纲一致

### 18. 教学方法适配
- [ ] 内容组织是否便于教学
- [ ] 是否提供了教学建议
- [ ] 案例是否贴近实际

### 19. 学习支持充分
- [ ] 是否提供了学习提示
- [ ] 是否标注了重点和难点
- [ ] 是否提供了扩展阅读

### 20. 评估方式合理
- [ ] 习题类型是否多样
- [ ] 习题是否覆盖教学目标
- [ ] 是否包含形成性评估

## 整体维度
### 21. 篇幅适中
- [ ] 篇幅是否与大纲要求匹配
- [ ] 是否存在过度展开或过于简略

### 22. 与前后章节衔接
- [ ] 是否回顾了前置知识
- [ ] 是否为后续章节做了铺垫
- [ ] 跨章引用是否正确
