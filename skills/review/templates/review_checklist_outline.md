# 大纲审查检查清单

## 1. 知识完整性
- [ ] 核心知识点是否覆盖课标要求
- [ ] 是否有遗漏的重要概念
- [ ] 知识点之间是否有逻辑缺口

## 2. 逻辑递进性
- [ ] 章节排列是否符合认知递进规律
- [ ] 前后章节是否有合理的知识衔接
- [ ] 难度梯度是否平缓递增

## 3. 认知层次分布
- [ ] 记忆层次内容占比是否合理（10-20%）
- [ ] 理解层次内容占比是否合理（20-30%）
- [ ] 应用层次内容占比是否合理（20-30%）
- [ ] 分析层次内容占比是否合理（15-25%）
- [ ] 评价层次内容占比是否合理（5-15%）
- [ ] 创造层次内容占比是否合理（5-10%）

## 4. 课标符合度
- [ ] 是否完全覆盖课标要求的知识点
- [ ] 能力要求是否与课标一致
- [ ] 教学时长分配是否合理

## 5. 篇幅均衡性
- [ ] 各章篇幅是否均衡
- [ ] 重点章节是否给予足够篇幅
- [ ] 是否存在过于冗长或过于简略的章节

## 6. 前置依赖正确性
- [ ] 各章前置知识是否在前面章节已覆盖
- [ ] 是否存在循环依赖
- [ ] 知识引入顺序是否合理

## 7. 术语一致性
- [ ] 同一概念是否使用统一术语
- [ ] 术语定义是否前后一致
- [ ] 是否存在同义异名情况

## 8. 实践环节覆盖
- [ ] 是否包含实验/实训环节
- [ ] 习题类型是否多样
- [ ] 实践环节与理论内容是否匹配
