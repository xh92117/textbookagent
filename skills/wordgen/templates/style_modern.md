# 现代简约模板 (modern)

## 字体设置
| 元素 | 中文字体 | 西文字体 | 字号 | 颜色 |
|------|---------|---------|------|------|
| 一级标题 | 微软雅黑 | Segoe UI | 20pt | #1A1A2E |
| 二级标题 | 微软雅黑 | Segoe UI | 16pt | #16213E |
| 三级标题 | 微软雅黑 | Segoe UI | 14pt | #0F3460 |
| 正文 | 微软雅黑 | Segoe UI | 11pt | #333333 |
| 代码 | 等线 | Consolas | 10pt | #555555 |
| 题注 | 微软雅黑 | Segoe UI | 9pt | #888888 |

## 段落设置
| 元素 | 行距 | 段前 | 段后 | 首行缩进 |
|------|------|------|------|---------|
| 一级标题 | 单倍 | 30pt | 15pt | 无 |
| 二级标题 | 单倍 | 20pt | 10pt | 无 |
| 三级标题 | 单倍 | 15pt | 8pt | 无 |
| 正文 | 1.75倍 | 0pt | 3pt | 2字符 |
| 代码块 | 单倍 | 8pt | 8pt | 无 |

## 页面设置
- 纸张: A4
- 页边距: 上下2cm，左右2.5cm
- 页眉: 章节名称（小五号，右对齐）
- 页脚: 页码（小五号，居中）
