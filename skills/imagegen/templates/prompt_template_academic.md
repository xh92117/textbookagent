# 学术风格图片提示词模板

## 通用学术风格约束
```
professional academic illustration, textbook quality,
clean and precise line work, scientific accuracy,
labeled with Chinese annotations where appropriate,
suitable for academic publication,
white or light gray background,
CMYK-friendly color palette
```

## 学科专用约束

### 理工科
```
precise technical drawing, engineering standards compliant,
dimensional accuracy, cross-hatching for sections,
standard symbols and notation
```

### 计算机科学
```
clean schematic diagram, UML-style notation where applicable,
data flow arrows, algorithm visualization,
pseudocode-friendly layout
```

### 生命科学
```
biological illustration, anatomical accuracy,
staining-appropriate color coding,
scale bars included, taxonomic labels
```

### 经济管理
```
business diagram style, corporate color scheme,
infographic elements, data visualization,
professional chart aesthetics
```

### 人文社科
```
historical illustration style, period-appropriate details,
map-quality cartography where applicable,
timeline visualization, archival aesthetic
```
