项目概览
TextBookAgent 是一个面向教材编制场景的智能体系统，核心能力是将用户上传的论文、文档和网络资源转化为结构化知识，并通过多智能体协作管线自动生成高质量教材。

🧠

⚡ 核心技术亮点

🔍 LLM-WIKI 索引范式

每个知识分块携带 use_when 场景描述和 content_type 分类（concept/procedure/evidence/reference），让 LLM 精准判断何时使用该知识

🌙 Deep Dream 记忆蒸馏

模拟人脑睡眠整理，6 大操作（合并提炼/新增萃取/冲突更新/清理无效/删除冗余/结构分组），将日记蒸馏为 ≤50 条永久记忆

🗜️ 84% 上下文压缩

骨架提取节约 70%、前序摘要节约 85%、状态板节约 97%，总压缩率 84%，让 85,000 chars 原始内容压缩到 13,300 chars 注入

🔄 搜索-知识闭环

每抓取一个来源立即 knowledge_capture 保存 → mark_dirty() 触发索引 → 后续 memory_search 自动召回，形成搜索→捕获→索引→检索的完整闭环

📚
知识库系统
知识库是智能体的"参考书架"，负责从文档中提取、组织和检索知识，为教材编写提供精准证据支撑。

📖 LLM-WIKI 索引

每个知识分块携带 use_when 场景描述，content_type 四分类：

concept 概念 procedure 步骤 evidence 数据 reference 参考

🔍 三路融合检索

  • BM25 — 词频+逆文档频率，k1=1.4 b=0.72
  • 元数据加权 — title×3.0 keywords×2.0
  • 图谱扩展 — 实体共现+0.75 关联+0.50

🛡️ 知识捕获五重守卫

  • URL 协议检查（仅 http/https）
  • 搜索引擎结果页过滤
  • 内容长度检查（≥180 chars）
  • 理由充分性（≥12 chars）
  • SHA-256 去重

记忆系统
记忆系统是智能体的"长期大脑"，7 种记忆类型覆盖从实时对话到永久知识的完整光谱，4 种更新机制确保信息不丢失且不过载。

🔄 记忆生命周期

1

对话产生 → 实时记录

每轮对话即时写入 JSONL，零延迟，无 LLM 调用

2

上下文裁剪 → 触发刷写

Token 超限时 LLM 异步摘要，写入日记，回调注入保持连续性

3

文件同步 → 索引入库

SHA-256 增量同步，分块+Embedding+FTS5 索引

4

Deep Dream → 长期蒸馏

定期提炼为 ≤50 条永久记忆，冲突以新信息为准

5

检索召回 → 上下文注入

向量(0.7)+关键词(0.3) 双路融合，时间衰减排序

6

时间衰减 → 自然遗忘

半衰期 30 天指数衰减，非日期型"常青"永不过期

⚡ 即时保存原则

SKILL.md 明确要求：每抓取一个可信来源，立即调用 knowledge_capture 保存

💡 原因

长搜索会话可能被上下文压缩，未保存的来源会丢失。即时保存确保每个有价值的来源都被持久化到知识库，后续 memory_search 自动召回。
