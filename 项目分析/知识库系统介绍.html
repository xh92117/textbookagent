知识库全景概览
TextBookAgent 知识库是教材编制智能体的"记忆大脑"，负责从用户上传的论文、文档和资料中提取、组织和检索知识，为教材编写提供精准证据支撑。

🎯 设计目标

  • 让教材编写过程能检索用户上传的论文、文档、资料和图片资产
  • 控制进入模型上下文的长度，避免全量注入导致 token 浪费
  • 支持增量整理，只处理未整理或已变更的文件
  • 为每个知识分块生成结构化元数据，实现精准匹配
  • 构建实体关系图谱，支持关联推理和扩展检索

📐 核心设计原则

  • 本地优先 — 无需外部向量数据库，BM25+元数据+图谱三路检索
  • Embedding Ready — 预留向量索引结构，商业化时平滑升级
  • LLM-WIKI 范式 — 每个 chunk 携带 use_when 场景描述
  • 增量索引 — 基于内容哈希判断变更，跳过已索引文件
  • 双模式整理 — Fast（本地规则）/ Deep（LLM 提取）可切换

LLM-WIKI 索引结构
LLM-WIKI 是知识库的核心存储范式，借鉴 Agent Skill 元数据思路，让每个知识分块携带"何时使用"的场景描述。

📁 目录布局

knowledge/{book_id}/ ├── sources/ ← 用户上传的原始文件 │ └── web_xxx_hash.md ← 网页捕获 Markdown ├── _llm_wiki/ ← 核心索引区 │ ├── index.json ← 主索引 │ ├── graph.json ← 知识图谱 │ ├── chunks/ ← 分块原文+YAML元数据 │ ├── pages/ ← 合成 Wiki 页面 │ ├── embeddings/ ← 向量索引(预留) │ ├── assets/ ← 抽取的图片资产 │ ├── cache/ ← 检索结果缓存 │ └── tasks/ ← 整理任务状态 ├── index.json ← 兼容性索引 └── cross_references.md ← 交叉引用

📋 index.json 核心字段

字段说明
sources已索引源文件记录
chunks知识分块（title/summary/use_when/keywords/content_type）
pages合成 Wiki 页面
entities提取的实体
relations实体间关系
embedding向量索引配置

🏷️ content_type 分类

📖 concept 定义/概念 🔧 procedure 步骤/方法 📊 evidence 数据/公式 📚 reference 通用参考

🏷️ Chunk 元数据示例（YAML Front Matter）

--- id: source_hash_chunk_001 source: 教材原文.pdf title: 结构力学基本原理 section: 第三章 结构分析 summary: 介绍了结构力学的基本假设与分析方法... use_when: Use this chunk when the task needs evidence, definitions, examples, or source details about 结构力学、受力分析. content_type: concept keywords: - 结构力学 - 受力分析 - 平衡条件 related_entities: - 弯矩 - 剪力 ---

多策略检索引擎
KnowledgeRetriever 实现三路融合检索，无需外部向量数据库即可提供高质量知识召回。

📦 Evidence Pack 输出

  • 完整版 — 含 excerpt 原文摘录，适合深度分析
  • 精简版 — metadata-first，仅 Top 匹配含 excerpt，大幅减少 token
  • 每个证据包含：chunk_id / score / title / summary / use_when / keywords / entities / citation

⚡ 检索缓存机制

  • 基于 SHA-256 的查询缓存，键由 query + limit + index_mtime 组成
  • 索引更新后缓存自动失效，保证结果一致性
  • 缓存 JSON 存储在 _llm_wiki/cache/ 目录
  • 避免重复计算 BM25 和元数据评分，加速高频查询

知识图谱构建
自动从文档中提取实体和关系，构建可交互的知识图谱，支持聚焦探索和关联推理。

🔗 图谱构建流程

1

实体抽取

LLM 模式由大模型提取领域实体；Fast 模式从关键词自动生成概念实体

2

关系推理

LLM 提取语义关系（包含/依赖/引用），附带置信度和证据文本

3

图谱投影

聚焦模式（BFS 扩展）/ 搜索模式（关键词匹配）/ 概览模式（度排序 Top-N）

4

交叉引用

自动建立知识条目间交叉引用，生成 cross_references.md

🎯 投影参数

参数范围说明
limit20~500返回节点数上限
depth1~3聚焦扩展深度
focus_id节点 ID聚焦起点
query文本搜索关键词
min_confidence0.0~1.0最低置信度

知识捕获工具
KnowledgeCapture 是 Agent Tool，允许智能体在浏览网页时将有价值的来源自动保存到知识库。

📋 输入参数

参数必填说明
url必填原始来源 URL
content必填提取的网页内容
reason必填为何有用（≥12字符）
title可选来源标题
book_id可选目标教材 ID
tags可选主题标签数组
force可选跳过质量检查

🛡️ 五重质量守卫

🔒

URL 协议检查

仅接受 http/https，拒绝本地路径

🚫

搜索引擎过滤

自动拒绝 Google/Baidu/Bing 搜索结果页

📏

内容长度检查

少于 180 字符的来源判定为信息不足

✍️

理由充分性

保存理由需 ≥12 字符，确保未来可追溯

🔄

去重机制

基于 URL+内容 SHA-256 哈希去重
